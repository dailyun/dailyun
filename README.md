## Building

### [TodoTodoList](https://github.com/dailyun/TTL)

A personal workspace for ideas, tasks, calendars, and the decisions to leave things undone. Optional integrations connect Markdown files, GitHub snapshots, Google Calendar, and external tools through a REST API.

**TypeScript · React · Next.js · PWA**

[Explore the project](https://github.com/dailyun/TTL) · [中文介绍](https://github.com/dailyun/TTL/blob/main/README.zh-CN.md) · [Share feedback](https://github.com/dailyun/TTL/issues)
